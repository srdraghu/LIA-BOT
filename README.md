# LIA-BOT
Developed a personal voice assistant that works on Speech Recognition and can communicate. 
A voice bot with a comedy dialogue management entertain system that take prompts from user and response with cine comedy dialogues. 
An intelligent voice bot to automate customer support and capable of understanding queries and prompts and responding to user effectively and take third applications actions. 
A special feature Voice remainder enabled in bot which user can set alarm remainder and prompt for voice remainder that enables to make remainder in AI voice like Jarvis. 
Voice remainder system that acts as friend and remainder system that helps to remind the tasks everyday. 
User friendly voice bot and primarily aimed for entertainment purpose and secondary as customer support and access third party webs and applications and special feature as voice remainder. 
Robust Dialogue management system to handle multi-turn conversations. Implemented fallback mechanisms for handling unrecognized queries or errors and ensuring handling of customer support. 

Key features : Speech Recognition , Voice assistant , Entertainment voice interaction , Query understanding. 

Technology Stack : Python frameworks , speech recognizer , pyttsx3 , pywhatkit and voice engine.
